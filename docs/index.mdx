Hitty brings shells, coding agents, project files, and remote machines into one
native workspace. Keep work running when the window closes, see which agent needs
you, and review its changes beside the terminal.

## Quick start

1. Download the package for your system from [GitHub Releases](https://github.com/cloudy-liu/hitty/releases/latest).
2. Open Hitty, choose your shell in Settings, and open a project directory.
3. Start an agent such as `codex`, `claude`, or `gemini`. Add a tab or split pane for another task and open files to review its work.

[Installation](/getting-started/installation) · [First launch](/getting-started/first-launch) · [中文介绍](https://github.com/cloudy-liu/hitty/blob/main/README.zh-CN.md)

## Core capabilities

<CardGroup cols={2}>
  <Card title="Persistent sessions" icon="power-off" href="/getting-started/concepts">
    Close and reopen the window to reattach to running shells. Restore saved
    workspaces, scrollback, and supported Agent conversations after a restart.
  </Card>
  <Card title="Agent awareness" icon="robot" href="/agents/overview">
    Per-pane identity, working and input states, notifications, and conversation
    resume when the Agent's session ID is known.
  </Card>
  <Card title="Your preferred shell" icon="terminal" href="/reference/shell-integration">
    PowerShell, bash, zsh, fish, and Windows CMD/Clink, with prompt editing,
    history suggestions, and completion. Custom Cmder startup commands work too.
  </Card>
  <Card title="Read and edit" icon="file" href="/window/side-panel">
    File tabs, source editing, Markdown and Mermaid previews, and local HTML
    preview on Windows and macOS, alongside your terminal.
  </Card>
  <Card title="SSH and WSL" icon="server" href="/remote/workspaces">
    Saved connections, SFTP, forwarding, and remote workspaces where terminal,
    file, and Git operations run on the machine that owns them.
  </Card>
  <Card title="Git review" icon="code-branch" href="/git/source-control">
    Working-tree changes, split or unified diffs, commit history, and worktrees
    without losing the context of your active terminal session.
  </Card>
</CardGroup>

Closing a window leaves its server and processes running. Restarting the server
or machine stops those processes; Hitty restores saved state and eligible Agent
conversations rather than preserving running processes through a reboot.

## Drive it with the CLI

After starting Hitty, use the bundled command from a shell or script:

```bash
hitty doctor
hitty ls
hitty agents
hitty run -- cargo test
hitty pane ls --json
```

Use `hitty send`, `hitty capture`, and `hitty wait` with a pane address to interact
with a longer task. [CLI guide](/cli/overview) · [Command reference](/cli/reference)

## Customize your workspace

Choose fonts, appearance, keybindings, shell arguments, and layout in Settings.
The default terminal uses Hack at 15 px with a light theme. Windows selects
PowerShell 7 when installed, otherwise Windows PowerShell.

[Settings](/customization/settings) · [Themes](/customization/themes) · [Configuration](/reference/configuration)

## Downloads and help

Desktop packages are available for Windows x64, Linux x64, and macOS Apple Silicon
and Intel. Windows packages are unsigned; macOS packages use ad-hoc signing and
are not notarized. See the installation guide for platform requirements.
