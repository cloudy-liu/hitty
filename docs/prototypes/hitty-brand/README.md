# Approved Hitty brand direction

Direction 08 retains the existing double-pane application and tray artwork and
adds the rounded Hitty wordmark. The self-contained `index.html` and selected
images are preserved from the source workspace separately from the source
baseline. Earlier authorization/status notes in the source design records are
historical; the implementation scope is now confirmed in the bootstrap plan.

The production combinations are `assets/hitty-logo-light.svg` and
`assets/hitty-logo-dark.svg`, with corresponding copies under `docs/logo/` for
the documentation site. They use the original prototype's vector paths, icon
size, 25 px gap, and rounded wordmark. `final-logo.html` displays the final pair.

The README selects the matching variant for the reader's color scheme. The
standalone wordmark remains `assets/hitty-wordmark.svg`; application and tray
artwork remain unchanged. Alternative designs inside the prototype are history.
