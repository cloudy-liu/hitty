Keep active Codex tasks marked working, respect SSH group icon settings, simplify nested Herdr panes, and name the Qoder integrations Qoder and Qoder CN.

## Highlights

- Keep Codex marked working while a tool call waits above a bordered input box (cloudy-liu/ctty7#257).
- Give nested Herdr workspaces the full pane area without overlapping host controls (cloudy-liu/ctty7#258).
- Name the Qoder integrations Qoder and Qoder CN in pane titles, Settings, tray labels, hook diagnostics, and `tty7 tab ls --json` (cloudy-liu/ctty7#260).

## Changes

### Changed

- Hide the host title, split/zoom/close toolbar, drag grip, and reserved top inset when Herdr owns the foreground pane (cloudy-liu/ctty7#258).
- Drop the redundant CLI suffix from the Qoder and Qoder CN agent labels wherever tty7 prints an agent name (cloudy-liu/ctty7#260).

### Fixed

- Recognize live Codex timeout timers above input-box borders so static titles cannot incorrectly mark active tool calls idle (cloudy-liu/ctty7#257).
- Apply folder and arrow visibility settings consistently to SSH and local project group headers (cloudy-liu/ctty7#255).

### Internal

- Record the latest Herdr manifest source revision while retaining identical upstream rule bytes (cloudy-liu/ctty7#257).
- Keep Markdown selection coverage independent of platform font height by clicking the measured heading center (cloudy-liu/ctty7#257).
- Reconcile patch-equivalent attention-size history without adding behavior already shipped in v0.11.0 (cloudy-liu/ctty7#258).
- Stabilize commit diff probe and pane title agent socket tests (cloudy-liu/ctty7#261).

## Known limitations

- The Codex fix was verified with a screen-layout regression fixture; the original live tool-timeout session was not retested.
- Matched native Before/After captures for hidden Herdr pane controls remain unavailable; visual acceptance is unverified.
- The Qoder rename was captured for pane titles and Settings → Agents; tray and CLI output share the same labels but were not captured separately.
- A live Qoder pane's own terminal title and TUI banner still read Qoder CLI; tty7 only controls the labels it prints.
- Windows packages are unsigned; macOS packages use ad hoc signatures and are not notarized.
- Interactive installation and in-place upgrades of the final packages have not been verified.
